Billero – Release notes

Zadnja posodobitev: junij 2026

Tu objavljamo povzetek novosti in popravkov po verzijah.

1.6.1 (junij 2026)

  • Zanesljivejši nakup naročnine — odpravljen obtičal nalagalni zaslon ob nakupu in obnovi naročnine (30-sekundni timeout + dodatni varnostni watchdog + jasna napaka).
  • Varnostne kopije s prejetimi računi — backup zdaj vključuje tudi datoteke prejetih računov (popravek za iOS po nadgradnji).
  • Lokalizirana stena naročnine — paywall (Mesečno / Letno / POPULARNO / opisi paketov) zdaj preveden v vse jezike vmesnika (13 jezikov).
  • Release notes v jeziku uporabnika — gumb »Release notes« zdaj odpre opombe k izdaji v jeziku aplikacije.

1.6.0 (maj 2026)

Velika verzija s freemium modelom in stabilnostnimi izboljšavami.

🆕 Naročnine — 2 nova paketa (Plus / Pro)

  • Plus (€3,99/mes ali €29/leto) — neomejeno računov, brez "Created with Billero" oznake, multi-language PDF, ARES/VIES auto-fill, popusti, ponavljajoči računi, auto-backup, 50 OCR scanov/mes
  • Pro (€7,99/mes ali €59/leto) — vse iz Plus + Predračun, avto-spomniki za neplačnike, Dashboard, neomejeni OCR scani
  • Trenutni naročniki dobijo Pro lifetime brezplačno kot kompenzacijo
  • Vsi obstoječi userji dobijo 3-mesečni Plus trial ob nadgradnji

🔒 Varnost in stabilnost

  • Šifriran backup — varnostne kopije so zdaj lahko AES-256 zaščitene z geslom (priporočeno ob deljenju). Brez gesla ostane backup nešifriran (kompatibilno s starimi).
  • Opt-in API ključi v backupu — API ključi tretjih oseb (npr. Anthropic) privzeto NISO vključeni v backup (zaščita pred slučajnim leak-om). Eksplicitno checkbox-aš pri izvozu.
  • Crash reporting — Firebase Crashlytics integriran (samo v release buildu). Napake na napravah so zdaj vidne razvijalcu.
  • Hitrejša baza — dodanih 14 indeksov za pogoste poizvedbe (seznami računov, dashboard, audit log). Pri 1000+ računih opazno hitrejši odziv.
  • Foreign key zaščita — DB zdaj enforce-a referenčno integriteto (ni več orphan postavk po brisanju računa).

🛠️ Pod motorjem (za razvijalce)

  • GitHub Actions CI — vsak commit gre skozi flutter analyze + test + Android debug build
  • 473→487 testov — dodani migration framework, backup round-trip, entitlement service testi
  • Cloudflare Worker — server-side IAP receipt validation za zaščito pred bypass-om
  • Migration v37 → v39 — z avtomatskim cleanup-om orphan zapisov pred FK enable-om

1.5.1 (april 2026)

  • Razdelek Računovodja — e-mail računovodje je zdaj v svojem razdelku v Moji podatki (ni več skupaj z AI ključi). Naslov preveden v vseh 12 jezikov.
  • Pošlji računovodji — gumb ✉↑ zdaj v eni pošti pošlje tako neposlane izdane račune kot neposlane prejete račune.
  • Navodila za uporabo — dodan zavihek »Računovodja« z navodili v vseh 12 jezikih.
  • OCR popravek — pri skeniranju izdanega računa (PDF) se zdaj pravilno zaznava kupec (ne dobavitelj).
  • Varnostna kopija — backup zdaj vključuje tudi nastavitev jezika aplikacije.
  • Obrezovanje slik — pri uvozu prejetih računov (kamera ali galerija) je zdaj na voljo obrezovanje slike pred shranjevanjem.

1.5.0 (april 2026)

  • Izbira jezika aplikacije — v Moji podatki lahko ročno izbereš jezik vmesnika (neodvisno od sistemskega).
  • Privzeti jezik PDF računa — račun se privzeto generira v primarnem jeziku države podjetja.
  • Boljše napake Anthropic API — ob preobremenjenosti strežnika (HTTP 529) se prikaže razumljivo sporočilo in samodejni ponovni poskus.
  • Filter »Stornirani« — v seznamu računov dodan filter za stornirane račune.
  • Pošlji neposlane računovodji — hitra akcija za serijski pošiljanje vseh neposlanih računov računovodji.
  • Analitika strank — popravek: stornirani računi se pravilno izključijo iz seštevkov.
