คู่มือผู้ใช้

คำแนะนำสั้น ๆ สำหรับการใช้ Billero

เริ่มต้นอย่างรวดเร็ว

  • กรอกข้อมูล รายละเอียดของฉัน (IBAN ที่อยู่ หมายเลขภาษี …)
  • เพิ่ม ลูกค้า (บริษัทหรือบุคคล)
  • สร้าง ใบแจ้งหนี้ใหม่ (ปกติหรือหลายรายการ)
  • คุณสามารถแบ่งปันหรือบันทึก PDF ได้ การแก้ไขใบแจ้งหนี้จะสร้าง PDF ใหม่

ใบแจ้งหนี้หลายรายการ

  • แต่ละรายการมีคำอธิบาย จำนวน หน่วย ราคา และอัตราภาษีมูลค่าเพิ่ม
  • บนหน้าจอที่เล็กกว่า ฟิลด์จะโยงไปมาอย่างอัตโนมัติเพื่อให้อ่านได้ง่ายขึ้น

การส่งใบแจ้งหนี้ไปยังลูกค้า

จากการ์ดรายละเอียดลูกค้า คุณสามารถเลือกและส่งใบแจ้งหนี้หลายใบพร้อมกันได้อย่างรวดเร็ว

  • เปิดแท็บ ลูกค้า แล้วแตะลูกค้า
  • กดค้าง ใบแจ้งหนี้ → เข้าสู่โหมดการเลือก
  • แตะใบแจ้งหนี้เพิ่มเติมเพื่อเลือกหรือยกเลิกการเลือก
  • ในแถบชื่อเรื่อง แตะ ↗ เพื่อแบ่งปัน PDF ที่เลือก
  • เพื่อออกจากโหมดการเลือก แตะ ✕ ในแถบชื่อเรื่อง

ใช้งานเหมือนกันสำหรับบริษัทและบุคคล (รวมถึงลูกค้าที่ไม่รู้จัก)

ใบแจ้งหนี้ที่ได้รับพร้อม AI OCR

Billero สามารถอ่านผู้จัดจำหน่าย หมายเลข วันที่ และจำนวนเงินจากใบแจ้งหนี้ PDF โดยอัตโนมัติโดยใช้ AI (Anthropic Claude) คุณสมบัติน้ำหนักแบบทำให้มีนัยสำคัญและต้องใช้ API key ของคุณเอง

รับ API key

  1. ไปที่ console.anthropic.com และสร้างบัญชี
  2. ในเมนู เลือก API Keys → Create Key
  3. ตั้งชื่อคีย์ (เช่น Billero) แล้วคัดลอก คีย์เริ่มต้นด้วย sk-ant-
  4. คุณต้องเพิ่มวิธีการชำระเงินในคอนโซล Anthropic การอ่านใบแจ้งหนี้หนึ่งใบราคา น้อยกว่า €0.001 (รุ่น Claude Haiku)

การตั้งค่าในแอป

  1. เปิด รายละเอียดของฉัน (⚙ tab) → ส่วน Anthropic API key (OCR)
  2. วางคีย์ในฟิลด์แล้วแตะ บันทึก
  3. คีย์จะถูกเก็บไว้ในพื้นที่ปลอดภัยของอุปกรณ์ของคุณ — ไม่เคยเขียนลงในไฟล์แอป

การใช้งาน

  1. ในแท็บ ใบแจ้งหนี้ แตะไอคอน ↑ (นำเข้า PDF) แล้วเลือก PDF ของใบแจ้งหนี้ที่ได้รับ
  2. แบบฟอร์มจะเปิดขึ้น แตะปุ่ม ✨ วิเคราะห์ด้วย AI
  3. รอสักครู่ — ฟิลด์ผู้จัดจำหน่าย หมายเลข วันที่ และจำนวนเงินจะถูกกรอกโดยอัตโนมัติ
  4. ตรวจสอบและแก้ไขหากจำเป็น จากนั้นแตะ บันทึก

หากไม่มี API key แบบฟอร์มจะทำงานเหมือนเดิม — กรอกฟิลด์ทั้งหมดด้วยตนเอง ปุ่ม AI จะไม่ปรากฏ

การสำรองข้อมูลและการคืนค่า

ข้อมูลทั้งหมดของคุณ (ใบแจ้งหนี้ ลูกค้า การตั้งค่า และ PDF) สามารถส่งออกและคืนค่าได้จากแท็บ รายละเอียดของฉัน → ส่วน Backup

ส่งออก

  • แตะ ส่งออก Backup
  • แอปสร้างไฟล์ ZIP (billero_backup_YYYY-MM-DD.zip) และเปิดแผ่นการแบ่งปัน
  • บันทึกไฟล์ไป iCloud Google Drive อีเมล หรือที่ไหนก็ได้ที่คุณต้องการ

คืนค่า (เช่น หลังจากเปลี่ยนโทรศัพท์)

  • ติดตั้ง Billero บนโทรศัพท์เครื่องใหม่
  • เปิด รายละเอียดของฉัน → คืนค่าจาก Backup
  • ยืนยันคำเตือน (ข้อมูลที่มีอยู่จะถูกแทนที่)
  • เลือกไฟล์ ZIP จากตำแหน่งจัดเก็บข้อมูลของคุณ
  • ใบแจ้งหนี้ ลูกค้า การตั้งค่า PDF โลโก้ และลายเซ็นดิจิทัลทั้งหมดจะถูกคืนค่า

คำเตือน: การคืนค่าจะแทนที่ข้อมูลที่มีอยู่ทั้งหมด เราขอแนะนำให้ส่งออก Backup ของข้อมูลปัจจุบันของคุณก่อนการคืนค่า

ใบแจ้งหนี้ที่เกิดซ้ำ

Billero สร้างใบแจ้งหนี้ปกติ (รายสัปดาห์ รายเดือน หรือรายไตรมาส) โดยอัตโนมัติทุกครั้งที่แอปเปิดใช้งาน

  1. ในแท็บ ใบแจ้งหนี้ แตะไอคอน ↻ (มุมขวาบน) → ใบแจ้งหนี้ที่เกิดซ้ำ
  2. แตะ + แล้วกรอก: ชื่อเทมเพลต ลูกค้า คำอธิบายบริการ จำนวนเงิน (ไม่รวมภาษี) อัตราภาษี
  3. เลือกความถี่: รายสัปดาห์ รายเดือน หรือ รายไตรมาส
  4. สำหรับรายเดือน/รายไตรมาส เลือกวันของเดือน (1–28)
  5. เมื่อแอปเปิดใช้งานครั้งต่อไปในหรือหลังวันที่กำหนดไว้ ใบแจ้งหนี้จะถูกสร้างขึ้นโดยอัตโนมัติพร้อมกับ PDF

เทมเพลตสามารถปิดใช้งานด้วยการสลับหรือแก้ไขได้ตลอดเวลา ใบแจ้งหนี้ที่สร้างขึ้นจะปรากฏในรายชื่อใบแจ้งหนี้หลัก

Thailand — ใบแจ้งหนี้แบบทวิภาษี (ไทย + ภาษาอังกฤษ)

เมื่อโปรไฟล์ของคุณตั้งค่าเป็น Thailand (TH) Billero จะสร้างใบแจ้งหนี้ PDF แบบทวิภาษี โดยอัตโนมัติ: ป้ายชื่อทุกรายการจะพิมพ์ในไทย (ด้านบน) และภาษาอังกฤษ (ด้านล่าง) ด้านข้างกันบนหน้าเดียวกัน

  • ฟอนต์ไทย (Noto Sans Thai) รวมอยู่ในแอป — ไม่จำเป็นต้องติดตั้ง
  • ใช้ได้สำหรับลูกค้าไทยท้องถิ่นและลูกค้าต่างประเทศที่ไม่อ่านไทย
  • อัตราภาษี: 7% (Revenue Code Section 77) เกณฑ์การลงทะเบียน: THB 1800000/ปี

Singapore — ใบแจ้งหนี้ GST

เมื่อโปรไฟล์ของคุณตั้งค่าเป็น Singapore (SG) Billero จะใช้กฎ GST โดยอัตโนมัติ:

  • อัตรา GST: 9% (GST Act Chapter 117A)
  • เกณฑ์การลงทะเบียน: SGD 1000000/ปี — ต่ำกว่าเกณฑ์จะพิมพ์ข้อปฏิเสธ
  • สกุลเงิน: SGD ($) เงื่อนไขการชำระเงิน: 30 วัน
