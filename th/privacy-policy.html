Billero – นโยบายความเป็นส่วนตัว

อัปเดตล่าสุด: พฤศจิกายน 2026 (แอปเวอร์ชัน 1.8.1)

Billero เป็นแอปออกใบแจ้งหนี้แบบ local-first ใบแจ้งหนี้ ใบเสนอราคา ลูกค้า และโปรไฟล์ธุรกิจของคุณถูกจัดเก็บไว้บนอุปกรณ์ของคุณ Billero ไม่มีบัญชีผู้ใช้หรือการเข้าสู่ระบบ เราไม่ได้ใช้งานเซิร์ฟเวอร์ที่รับข้อมูลธุรกิจของคุณ และเราไม่มีสำเนาของข้อมูลดังกล่าว นโยบายนี้อธิบายว่าข้อมูลจำนวนจำกัดใดบ้างที่ออกจากอุปกรณ์ของคุณ เมื่อใด และส่งไปถึงใคร

1. ข้อมูลที่จัดเก็บบนอุปกรณ์ของคุณ

ข้อมูลต่อไปนี้จัดเก็บไว้บนอุปกรณ์ของคุณเท่านั้น ในฐานข้อมูลในเครื่อง (SQLite) และในไฟล์ของแอป:

  • ใบแจ้งหนี้ที่ออกและที่รับ ใบเสนอราคา และเอกสารที่เกี่ยวข้อง (PDF รูปภาพ)
  • ข้อมูลลูกค้าที่คุณป้อน (ชื่อ ที่อยู่ เลขประจำตัวผู้เสียภาษี ที่อยู่อีเมล)
  • โปรไฟล์ธุรกิจของคุณ (รายละเอียดบริษัท หมายเลขทางภาษี บัญชีธนาคาร ลิงก์ชำระเงิน ที่อยู่กระเป๋าเงินคริปโต โลโก้ ลายเซ็น)
  • การตั้งค่าและค่ากำหนดของแอป

หากคุณถอนการติดตั้งแอป ข้อมูลนี้จะถูกลบออกจากอุปกรณ์ของคุณ เราไม่สามารถกู้คืนข้อมูลได้ ดังนั้นโปรดเก็บข้อมูลสำรองไว้ (หัวข้อ 4)

2. เมื่อใดที่ข้อมูลออกจากอุปกรณ์ของคุณ

2.1 รายงานการขัดข้องและข้อผิดพลาด – Firebase Crashlytics (Google LLC)

ในเวอร์ชันที่เผยแพร่ในสโตร์ แอปใช้ Firebase Crashlytics เพื่อตรวจหาและแก้ไขการขัดข้อง เมื่อแอปขัดข้องหรือบันทึกข้อผิดพลาดบางประเภท Google จะได้รับ:

  • Stack trace และข้อความแสดงข้อผิดพลาด (อาจมีรายละเอียดทางเทคนิคของการดำเนินการที่ล้มเหลว)
  • รุ่นอุปกรณ์ เวอร์ชันระบบปฏิบัติการ และเวอร์ชันแอป
  • ตัวระบุการติดตั้งแบบสุ่ม (Firebase Installation ID)
  • บรรทัดบันทึกทางเทคนิคสั้น ๆ เกี่ยวกับการซื้อ (ผลิตภัณฑ์และสถานะการซื้อ ไม่มีรายละเอียดการชำระเงินในทุกกรณี)

เราไม่แนบชื่อ ที่อยู่อีเมล หรือเนื้อหาใบแจ้งหนี้ของคุณไปกับรายงานเหล่านี้ และรายงานเหล่านี้ไม่ถูกใช้เพื่อการโฆษณา Google เก็บรายงานการขัดข้องไว้เป็นระยะเวลาจำกัดตามข้อกำหนดของ Firebase นโยบายความเป็นส่วนตัวของ Google: https://policies.google.com/privacy

2.2 การอ่านใบแจ้งหนี้ที่รับด้วย AI – Anthropic PBC (สหรัฐอเมริกา)

การอ่านด้วย AI เป็นทางเลือก จะไม่มีการส่งข้อมูลใด ๆ จนกว่าคุณจะให้ความยินยอมในแอป และหลังจากนั้นจะส่งเฉพาะเมื่อคุณเริ่มอ่านเอกสารเท่านั้น เอกสารที่เลือกหรือถ่ายภาพไว้ (รูปภาพหรือ PDF) จะถูกส่งทั้งฉบับไปยัง Anthropic ซึ่งจะดึงข้อมูลผู้ขายหรือผู้ซื้อ หมายเลข วันที่ จำนวนเงิน และคำอธิบาย ผลลัพธ์จะถูกบันทึกไว้บนอุปกรณ์ของคุณ เอกสารอาจมีข้อมูลส่วนบุคคลและข้อมูลทางการเงิน ภายใต้ข้อกำหนดเชิงพาณิชย์ของ Anthropic ข้อมูลที่ส่งผ่าน API ของ Anthropic จะไม่ถูกใช้เพื่อฝึกโมเดล Anthropic อาจเก็บข้อมูลไว้เป็นระยะเวลาจำกัดตามนโยบายการเก็บรักษาข้อมูลของตน หากคุณป้อนคีย์ API ของ Anthropic ของคุณเอง ข้อตกลงระหว่างคุณกับ Anthropic จะมีผลบังคับใช้ คุณสามารถถอนความยินยอมได้ทุกเมื่อในแอป (หน้าจอ “ธุรกิจ”) นโยบายความเป็นส่วนตัวของ Anthropic: https://www.anthropic.com/legal/privacy

2.3 อัตราแลกเปลี่ยนสำหรับคิวอาร์โค้ดชำระเงินด้วยคริปโต – Frankfurter และ CoinGecko

เฉพาะในกรณีที่คุณเพิ่มที่อยู่กระเป๋าเงินคริปโตในโปรไฟล์ของคุณ แอปจะดึงอัตราแลกเปลี่ยนเมื่อสร้าง PDF ใบแจ้งหนี้ที่มีคิวอาร์โค้ดชำระเงินด้วยคริปโต: จาก api.frankfurter.app (อัตราแลกเปลี่ยนสกุลเงิน) และ api.coingecko.com (ราคาคริปโต) คำขอมีเพียงรหัสสกุลเงิน (เช่น USD หรือ EUR) ไม่มีข้อมูลใบแจ้งหนี้หรือข้อมูลลูกค้า เช่นเดียวกับคำขอทางอินเทอร์เน็ตทุกรายการ ผู้ให้บริการจะเห็นที่อยู่ IP ของคุณ

2.4 ข้อความเมื่อเริ่มแอป – billero.app

เมื่อแอปเริ่มทำงาน แอปอาจโหลดข้อความสั้น ๆ จาก billero.app โดยไม่มีการส่งข้อมูลเกี่ยวกับคุณหรือใบแจ้งหนี้ของคุณ ผู้ให้บริการเว็บโฮสติ้งของเราอาจเก็บบันทึกเซิร์ฟเวอร์มาตรฐาน (เช่น ที่อยู่ IP และเวลาของคำขอ)

2.5 การซื้อ – Apple App Store และ Google Play

การสมัครสมาชิกซื้อและชำระเงินผ่าน Apple หรือ Google ซึ่งเป็นผู้จัดการวิธีการชำระเงินและบัญชีของคุณ เราไม่ได้รับรายละเอียดการชำระเงินของคุณ แอปได้รับการยืนยันการซื้อของคุณจากสโตร์บนอุปกรณ์ของคุณ ปัจจุบันเราไม่ได้ใช้งานเซิร์ฟเวอร์สำหรับตรวจสอบใบเสร็จการซื้อ หากเรานำเซิร์ฟเวอร์ดังกล่าวมาใช้ เราจะอัปเดตนโยบายนี้ก่อนเปิดใช้งาน

2.6 ข้อมูลที่คุณแชร์เอง

เมื่อคุณส่งใบแจ้งหนี้ ส่งออกไฟล์ CSV หรือแชร์ข้อมูลสำรอง แอปจะใช้เมนูแชร์หรือแอปอีเมลของอุปกรณ์ของคุณ คุณเป็นผู้เลือกผู้รับหรือปลายทาง และข้อกำหนดของบริการนั้นจะมีผลบังคับใช้ เราไม่ได้รับสำเนา

2.7 เว็บไซต์และหน้าดาวน์โหลด – billero.app

เว็บไซต์ billero.app ของเราโฮสต์โดย Cloudflare, Inc. (สหรัฐอเมริกา) ซึ่งอาศัย EU-US Data Privacy Framework เช่นเดียวกับทุกเว็บไซต์ เบราว์เซอร์ของคุณจะส่งที่อยู่ IP และรายละเอียดทางเทคนิค (เช่น ประเภทเบราว์เซอร์และอุปกรณ์) ไปพร้อมกับทุกคำขอ เมื่อคุณเปิดหน้าดาวน์โหลด billero.app/app เซิร์ฟเวอร์ของเราจะเพียงเพิ่มจำนวนการเข้าชมรายวันขึ้นหนึ่ง โดยนับแยกตามวัน รหัสแคมเปญในลิงก์ (เช่น จากโฆษณา) ภาษาของหน้า ประเภทอุปกรณ์ (iPhone หรือ iPad, Android, อื่น ๆ, การเข้าถึงอัตโนมัติ) และแอปที่เบราว์เซอร์ในตัวเปิดหน้านั้น (Facebook, Instagram หรือ TikTok) เราไม่เก็บที่อยู่ IP สตริงระบุเบราว์เซอร์ หรือตัวระบุใด ๆ ของคุณ จึงไม่สามารถแยกการเข้าชมแต่ละครั้งออกจากกันหรือเชื่อมโยงกับคุณหรือกับแอปได้ หน้าดาวน์โหลดไม่ตั้งค่าคุกกี้ นอกจากนี้ ทุกหน้าของเว็บไซต์ รวมถึงหน้าดาวน์โหลด จะโหลด Cloudflare Web Analytics ซึ่งเป็นสคริปต์ที่ส่งข้อมูลแบบไม่ระบุตัวตนเกี่ยวกับการเปิดดูหน้าไปยัง Cloudflare (ที่อยู่ของหน้า หน้าที่อ้างอิง ประเภทเบราว์เซอร์ ระบบปฏิบัติการและอุปกรณ์ ประเทศ เวลาในการโหลด) โดยไม่ใช้คุกกี้หรือตัวระบุ และเราเห็นเพียงยอดรวมเท่านั้น จำนวนเหล่านี้จะถูกลบหลังจาก 400 วัน ฐานทางกฎหมาย: ประโยชน์อันชอบธรรมของเราในการทราบว่ามีผู้เข้าชมเว็บไซต์กี่คนและลิงก์ใดนำผู้คนไปยังร้านแอป (มาตรา 6(1)(f) GDPR) สำหรับการเข้าชมและการติดตั้งในร้านแอป Apple และ Google แสดงให้เราเห็นเพียงยอดรวมแบบไม่ระบุตัวตนแยกตามแคมเปญเท่านั้น

3. สิทธิ์การเข้าถึงและการติดตาม

  • กล้องและรูปภาพ – เพื่อสแกนหรือเลือกใบแจ้งหนี้ที่รับ โลโก้ และลายเซ็นของคุณ
  • ไบโอเมตริกซ์หรือ PIN ของอุปกรณ์ – สำหรับการล็อกแอปซึ่งเป็นทางเลือก
  • การแจ้งเตือน – สำหรับการเตือนใบแจ้งหนี้ที่ถึงกำหนดชำระ การแจ้งเตือนถูกสร้างขึ้นบนอุปกรณ์ของคุณและไม่เคยถูกส่งมาถึงเรา
  • อินเทอร์เน็ต – สำหรับบริการในหัวข้อ 2

แอปไม่มี SDK โฆษณา และไม่มี SDK สำหรับการวิเคราะห์หรือการติดตาม ไม่ใช้รหัสโฆษณา และไม่ติดตามคุณข้ามแอปหรือเว็บไซต์ เราไม่ขายข้อมูลส่วนบุคคลและไม่แบ่งปันข้อมูลดังกล่าวเพื่อการโฆษณาตามพฤติกรรมข้ามบริบท

4. การสำรองข้อมูล

  • การสำรองข้อมูลอัตโนมัติ (Plus และ Pro เมื่อคุณเปิดใช้งาน): เข้ารหัสด้วยรหัสผ่านที่คุณตั้งไว้เสมอ (AES-256 รูปแบบ ZIP AES) หากไม่มีรหัสผ่าน จะไม่มีการสร้างข้อมูลสำรองอัตโนมัติ
  • การส่งออกด้วยตนเอง (หน้าจอ “ธุรกิจ”): รหัสผ่านเป็นทางเลือก หากมีรหัสผ่าน ไฟล์ ZIP จะถูกเข้ารหัสด้วย AES-256 หากไม่มีรหัสผ่าน ไฟล์จะไม่ถูกเข้ารหัส ดังนั้นโปรดจัดเก็บและแชร์ด้วยความระมัดระวัง
  • การส่งออกจากหน้าจอแพ็กเกจ (ก่อนการซื้อ): ไฟล์ ZIP ไม่ถูกเข้ารหัส

ชื่อไฟล์ภายในไฟล์ ZIP ไม่ถูกเข้ารหัส มีเพียงเนื้อหาของไฟล์เท่านั้นที่ถูกเข้ารหัส คีย์ API ของคุณเองจะรวมอยู่ในข้อมูลสำรองก็ต่อเมื่อคุณเปิดตัวเลือกนี้ (ปิดเป็นค่าเริ่มต้น) ข้อมูลสำรองจะถูกบันทึกไว้ในตำแหน่งที่คุณเลือก เราไม่เคยได้รับข้อมูลสำรองเหล่านั้น

5. สิทธิ์ของคุณ (GDPR, CCPA/CPRA และกฎหมายที่คล้ายกัน)

ข้อมูลธุรกิจของคุณอยู่บนอุปกรณ์ของคุณ คุณจึงสามารถดู แก้ไข ส่งออก หรือลบข้อมูลได้ทุกเมื่อในแอป หรือลบข้อมูลทั้งหมดได้ด้วยการถอนการติดตั้งแอป สำหรับรายงานการขัดข้อง (หัวข้อ 2.1) และคำถามอื่น ๆ โปรดเขียนถึง info@billero.app รายงานการขัดข้องเชื่อมโยงกับตัวระบุการติดตั้งแบบสุ่มเท่านั้น ไม่ได้เชื่อมโยงกับตัวตนของคุณ ดังนั้นโปรดแจ้งเราว่าคุณต้องการอะไร แล้วเราจะช่วยเหลือเท่าที่ข้อมูลสามารถระบุได้ คุณยังมีสิทธิ์ยื่นข้อร้องเรียนต่อหน่วยงานคุ้มครองข้อมูลของคุณ

6. เด็ก

Billero เป็นเครื่องมือทางธุรกิจสำหรับผู้ใช้ที่มีอายุ 18 ปีขึ้นไป ไม่ได้มุ่งเป้าไปที่เด็ก และเราไม่จงใจเก็บรวบรวมข้อมูลจากเด็ก

7. การโอนข้อมูลระหว่างประเทศ

Google (Firebase Crashlytics) และ Anthropic อาจประมวลผลข้อมูลในสหรัฐอเมริกาหรือประเทศอื่น ๆ ผู้ให้บริการเหล่านี้อาศัย EU-US Data Privacy Framework หรือข้อสัญญามาตรฐาน (Standard Contractual Clauses)

8. ความปลอดภัย

ข้อมูลบนอุปกรณ์ของคุณได้รับการปกป้องด้วยระบบความปลอดภัยของระบบปฏิบัติการ (Android, iOS) และด้วยการล็อกแอปหากคุณเปิดใช้งาน การเชื่อมต่อทั้งหมดที่อธิบายไว้ในหัวข้อ 2 ใช้ HTTPS

หากเราเปลี่ยนแปลงวิธีที่แอปจัดการข้อมูล เราจะอัปเดตหน้านี้และวันที่ "อัปเดตล่าสุด" ก่อนที่การเปลี่ยนแปลงจะมีผล
