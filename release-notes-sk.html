Billero – Poznámky k verzii

Posledná aktualizácia: jún 2026

Súhrn noviniek a opráv podľa verzií.

1.6.1 (jún 2026)

  • Spoľahlivejší nákup predplatného — opravené nekonečné načítavanie pri nákupe a obnovení (30-sekundový timeout plus pridaný bezpečnostný watchdog a jasná chybová správa).
  • Zálohy s prijatými faktúrami — záloha teraz obsahuje aj súbory prijatých faktúr (oprava pre iOS po aktualizácii).
  • Lokalizovaný paywall — paywall (Mesačne / Ročne / OBĽÚBENÉ / popisy balíkov) teraz preložený do všetkých jazykov rozhrania (13 jazykov).
  • Poznámky k verzii vo vašom jazyku — tlačidlo "Poznámky k verzii" teraz otvorí poznámky v jazyku aplikácie.

1.6.0 (máj 2026)

Veľké vydanie s freemium modelom a vylepšeniami stability.

🆕 Predplatné — 2 nové balíky (Plus / Pro)

  • Plus (€3,99/mes alebo €29/rok) — neobmedzené faktúry, bez označenia "Created with Billero", viacjazyčné PDF, ARES/VIES auto-fill, zľavy, opakujúce sa faktúry, auto-záloha, 50 OCR skenov/mes
  • Pro (€7,99/mes alebo €59/rok) — všetko z Plus + Cenová ponuka, pripomienky, Dashboard, neobmedzené OCR
  • Existujúci predplatitelia dostanú Pro lifetime zadarmo ako kompenzáciu
  • Všetci existujúci používatelia dostanú 3-mesačnú skúšobnú verziu Plus pri upgrade

🔒 Bezpečnosť a stabilita

  • Šifrovaná záloha — zálohy môžu byť chránené heslom AES-256.
  • Opt-in API kľúče v zálohe — API kľúče tretích strán (napr. Anthropic) NIE SÚ v zálohe predvolene.
  • Hlásenie pádov — Firebase Crashlytics integrovaný (iba release buildy).
  • Rýchlejšia databáza — 14 nových indexov pre časté dopyty.
  • Foreign key ochrana — DB teraz vynucuje referenčnú integritu.
