Resumo de novidades e correções por versão.

1.6.1 (junho 2026)

  • Compra de assinatura mais fiável — corrigido o carregamento infinito durante a compra e a restauração (timeout de 30 segundos mais um watchdog de segurança adicional e uma mensagem de erro clara).
  • Cópias com faturas recebidas — a cópia de segurança agora também inclui os ficheiros das faturas recebidas (correção para iOS após a atualização).
  • Paywall localizado — paywall (Mensal / Anual / POPULAR / descrições de planos) agora traduzido para todos os idiomas da interface (13 idiomas).
  • Novidades no seu idioma — o botão "Novidades" agora abre as notas no idioma da app.

1.6.0 (maio 2026)

Versão importante com modelo freemium e melhorias de estabilidade.

🆕 Assinaturas — 2 novos planos (Plus / Pro)

  • Plus (€3,99/mês ou €29/ano) — faturas ilimitadas, sem marca "Created with Billero", PDF multilíngue, ARES/VIES auto-fill, descontos, faturas recorrentes, backup automático, 50 digitalizações OCR/mês
  • Pro (€7,99/mês ou €59/ano) — tudo do Plus + Orçamento, lembretes, Dashboard, OCR ilimitado
  • Assinantes atuais recebem Pro lifetime grátis como compensação
  • Todos os utilizadores atuais recebem 3 meses de Plus em teste ao atualizar

🔒 Segurança e estabilidade

  • Backup criptografado — backups podem ser protegidos com senha AES-256.
  • Chaves API opt-in no backup — chaves API de terceiros (p. ex. Anthropic) NÃO estão no backup por padrão.
  • Relatório de falhas — Firebase Crashlytics integrado (apenas release).
  • Base de dados mais rápida — 14 novos índices para consultas frequentes.
  • Proteção Foreign key — DB agora aplica integridade referencial.
