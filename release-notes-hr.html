Billero – Bilješke o izdanju

Posljednje ažuriranje: lipanj 2026.

Sažetak novosti i ispravaka po verzijama.

1.6.1 (lipanj 2026.)

  • Pouzdanija kupovina pretplate — uklonjeno beskonačno učitavanje pri kupovini i obnovi (30-sekundni timeout plus dodatni sigurnosni watchdog i jasna poruka greške).
  • Sigurnosne kopije s primljenim računima — backup sada uključuje i datoteke primljenih računa (ispravak za iOS nakon nadogradnje).
  • Lokalizirani paywall — paywall (Mjesečno / Godišnje / POPULARNO / opisi paketa) sada preveden na sve jezike sučelja (13 jezika).
  • Bilješke o izdanju na vašem jeziku — gumb "Bilješke o izdanju" sada otvara bilješke na jeziku aplikacije.

1.6.0 (svibanj 2026.)

Veliko izdanje s freemium modelom i poboljšanjima stabilnosti.

🆕 Pretplate — 2 nova paketa (Plus / Pro)

  • Plus (€3,99/mj. ili €29/god.) — neograničeno računa, bez oznake "Created with Billero", višejezični PDF, ARES/VIES auto-fill, popusti, ponavljajući računi, auto-backup, 50 OCR skeniranja/mjesec
  • Pro (€7,99/mj. ili €59/god.) — sve iz Plus + Predračun, podsjetnici, Dashboard, neograničena OCR skeniranja
  • Postojeći pretplatnici dobivaju Pro lifetime besplatno kao kompenzaciju
  • Svi postojeći korisnici dobivaju 3-mjesečni Plus probni period pri nadogradnji

🔒 Sigurnost i stabilnost

  • Šifrirani backup — sigurnosne kopije sada mogu biti AES-256 zaštićene lozinkom.
  • Opt-in API ključevi u backupu — API ključevi trećih strana (npr. Anthropic) NISU uključeni u backup po defaultu.
  • Crash reporting — Firebase Crashlytics integriran (samo u release buildu).
  • Brža baza — 14 novih indeksa za česte upite.
  • Foreign key zaštita — DB sada osigurava referencijalni integritet.
