Billero – Informacje o wersji

Ostatnia aktualizacja: czerwiec 2026

Podsumowanie nowości i poprawek według wersji.

1.6.1 (czerwiec 2026)

  • Bardziej niezawodny zakup subskrypcji — naprawiono nieskończone ładowanie podczas zakupu i przywracania (30-sekundowy timeout oraz dodatkowy watchdog bezpieczeństwa i jasny komunikat błędu).
  • Kopie zapasowe z otrzymanymi fakturami — kopia zawiera teraz także pliki otrzymanych faktur (poprawka dla iOS po aktualizacji).
  • Zlokalizowany paywall — paywall (Miesięcznie / Rocznie / POPULARNE / opisy planów) przetłumaczony na wszystkie języki interfejsu (13 języków).
  • Informacje o wersji w Twoim języku — przycisk "Informacje o wersji" otwiera teraz notatki w języku aplikacji.

1.6.0 (maj 2026)

Duże wydanie z modelem freemium i ulepszeniami stabilności.

🆕 Subskrypcje — 2 nowe plany (Plus / Pro)

  • Plus (€3,99/mies. lub €29/rok) — nieograniczone faktury, bez oznaczenia "Created with Billero", PDF wielojęzyczne, ARES/VIES auto-fill, rabaty, faktury cykliczne, auto-kopia, 50 skanów OCR/mies.
  • Pro (€7,99/mies. lub €59/rok) — wszystko z Plus + Oferta, przypomnienia, Dashboard, nieograniczone OCR
  • Obecni subskrybenci otrzymują Pro lifetime za darmo jako rekompensatę
  • Wszyscy obecni użytkownicy otrzymują 3-miesięczny okres próbny Plus przy aktualizacji

🔒 Bezpieczeństwo i stabilność

  • Szyfrowana kopia zapasowa — kopie mogą być chronione hasłem AES-256.
  • Opt-in klucze API w kopii — klucze API stron trzecich (np. Anthropic) NIE są domyślnie w kopii.
  • Raportowanie awarii — Firebase Crashlytics zintegrowany (tylko release).
  • Szybsza baza danych — 14 nowych indeksów dla częstych zapytań.
  • Ochrona Foreign key — DB wymusza teraz integralność referencyjną.
