Billero – Release notes

Last updated: June 2026

Summary of new features and fixes by version.

1.6.1 (June 2026)

  • More reliable subscription purchase — fixed the loading spinner hanging during purchase and restore (30-second timeout plus an extra safety watchdog and a clear error message).
  • Backups include received invoices — your backup now also contains received-invoice files (fix for iOS after upgrade).
  • Localized paywall — paywall (Monthly / Yearly / POPULAR / plan descriptions) now translated into all interface languages (13 languages).
  • Release notes in your language — the "Release notes" button now opens notes in the app's language.

1.6.0 (May 2026)

Major release with freemium model and stability improvements.

🆕 Subscriptions — 2 new plans (Plus / Pro)

  • Plus (€3.99/mo or €29/yr) — unlimited invoices, no "Created with Billero" label, multi-language PDF, ARES/VIES auto-fill, discounts, recurring invoices, auto-backup, 50 OCR scans/mo
  • Pro (€7.99/mo or €59/yr) — everything in Plus + Quote/Proforma, reminders, dashboard, unlimited OCR
  • Existing subscribers receive Pro lifetime free as compensation
  • All existing users get a 3-month Plus trial on upgrade

🔒 Security and stability

  • Encrypted backup — backups can now be AES-256 password-protected (recommended when sharing).
  • Opt-in API keys in backup — third-party API keys (e.g. Anthropic) are NOT included in backup by default.
  • Crash reporting — Firebase Crashlytics integrated (release builds only).
  • Faster database — 14 new indexes for common queries.
  • Foreign key protection — DB now enforces referential integrity.
