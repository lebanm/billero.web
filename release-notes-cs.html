1.6.1 (červen 2026)

  • Spolehlivější nákup předplatného — opraveno nekonečné načítání při nákupu a obnovení (30-sekundový timeout plus přidaný bezpečnostní watchdog a jasná chybová zpráva).

1.6.0 (květen 2026)

Velké vydání s freemium modelem a vylepšeními stability.

🆕 Předplatné — 2 nové tarify (Plus / Pro)

  • Plus (€3,99/měs nebo €29/rok) — neomezené faktury, bez označení "Created with Billero", vícejazyčné PDF, ARES/VIES auto-fill, slevy, opakující se faktury, auto-záloha, 50 OCR skenů/měs
  • Pro (€7,99/měs nebo €59/rok) — vše z Plus + Cenová nabídka, upomínky, Dashboard, neomezené OCR
  • Stávající předplatitelé dostanou Pro lifetime zdarma jako kompenzaci
  • Všichni stávající uživatelé dostanou 3-měsíční zkušební Plus při upgrade

🔒 Bezpečnost a stabilita

  • Šifrovaná záloha — zálohy mohou nyní být chráněny AES-256 heslem.
  • Opt-in API klíče v záloze — API klíče třetích stran (např. Anthropic) NEJSOU ve výchozím nastavení v záloze.
  • Hlášení pádů — Firebase Crashlytics integrován (pouze release buildy).
  • Rychlejší databáze — 14 nových indexů pro časté dotazy.
  • Foreign key ochrana — DB nyní vynucuje referenční integritu.
