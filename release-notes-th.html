อัปเดตล่าสุด: มิถุนายน 2026

สรุปฟีเจอร์ใหม่และการแก้ไขแยกตามเวอร์ชัน

1.6.1 (มิถุนายน 2026)

  • การซื้อแพ็กเกจสมาชิกที่เชื่อถือได้มากขึ้น — แก้ไขการโหลดที่ค้างไม่หยุดขณะซื้อและกู้คืน (เพิ่ม timeout 30 วินาที พร้อม watchdog เพื่อความปลอดภัย และข้อความข้อผิดพลาดที่ชัดเจน)
  • การสำรองข้อมูลรวมใบแจ้งหนี้ที่ได้รับ — การสำรองข้อมูลจะรวมไฟล์ใบแจ้งหนี้ที่ได้รับด้วย (แก้ไขสำหรับ iOS หลังอัปเกรด)
  • Paywall ที่แปลภาษาแล้ว — Paywall (รายเดือน / รายปี / ยอดนิยม / รายละเอียดแพ็กเกจ) แปลเป็นทุกภาษาของอินเตอร์เฟซ (13 ภาษา)
  • บันทึกการอัปเดตในภาษาของคุณ — ปุ่ม "บันทึกการอัปเดต" จะเปิดบันทึกในภาษาของแอป

1.6.0 (พฤษภาคม 2026)

รุ่นใหญ่พร้อมโมเดล freemium และการปรับปรุงความเสถียร

🆕 แพ็กเกจสมาชิก — 2 แพ็กเกจใหม่ (Plus / Pro)

  • Plus (€3.99/เดือน หรือ €29/ปี) — ใบแจ้งหนี้ไม่จำกัด ไม่มีป้าย "Created with Billero" PDF หลายภาษา ARES/VIES auto-fill ส่วนลด ใบแจ้งหนี้ซ้ำ สำรองอัตโนมัติ OCR 50 ครั้ง/เดือน
  • Pro (€7.99/เดือน หรือ €59/ปี) — ทุกอย่างจาก Plus + ใบเสนอราคา เตือนความจำ Dashboard OCR ไม่จำกัด
  • สมาชิกปัจจุบันได้รับ Pro lifetime ฟรีเป็นค่าชดเชย
  • ผู้ใช้ปัจจุบันทุกคนได้รับ ทดลอง Plus 3 เดือนเมื่ออัปเกรด

🔒 ความปลอดภัยและความเสถียร

  • สำรองข้อมูลแบบเข้ารหัส — สำรองข้อมูลสามารถป้องกันด้วยรหัสผ่าน AES-256
  • คีย์ API แบบ opt-in ในสำรอง — คีย์ API ของผู้ให้บริการภายนอก (เช่น Anthropic) ไม่อยู่ในสำรองโดยค่าเริ่มต้น
  • รายงานข้อขัดข้อง — รวม Firebase Crashlytics (เฉพาะ release)
  • ฐานข้อมูลเร็วขึ้น — 14 ดัชนีใหม่สำหรับการสอบถามทั่วไป
  • การป้องกัน Foreign key — DB บังคับใช้ความสมบูรณ์ของการอ้างอิง
