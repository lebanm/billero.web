ユーザーガイド

Billeroの使い方の簡単なガイドです。

クイックスタート

  • マイ情報（IBAN、住所、税務番号など）を入力します。
  • 取引先（会社または個人）を追加します。
  • 新しい請求書（シンプルまたは複数項目）を作成します。
  • PDFを共有または保存できます。請求書を編集するとPDFが再生成されます。

複数項目の請求書

  • 各項目には、説明、数量、単位、価格、VAT税率があります。
  • 小さい画面では、読みやすさのためにフィールドが自動的に2行に折り返されます。

取引先への請求書の送信

取引先の詳細カードから、複数の請求書をすばやく選択して一度に送信できます。

  • 取引先タブを開き、取引先をタップします。
  • 請求書を長押しすると、選択モードに入ります。
  • 他の請求書をタップして選択または選択解除します。
  • タイトルバーで↗をタップすると、選択したPDFを共有できます。
  • 選択モードを終了するには、タイトルバーで✕をタップします。

会社にも個人にも（不明な取引先を含む）同じように機能します。

AI OCRによる受領請求書

Billeroは、AI（Anthropic Claude）を使用して、PDF請求書から供給者、番号、日付、金額を自動的に読み取ることができます。この機能は任意であり、お客様ご自身のAPIキーが必要です。

APIキーの取得

  1. console.anthropic.com にアクセスし、無料アカウントを作成します。
  2. メニューでAPI Keys → Create Keyを選択します。
  3. キーに名前を付け（例: Billero）、コピーします。キーはsk-ant-で始まります。
  4. Anthropicコンソールで支払い方法を追加する必要があります。請求書1件の読み取りコストは€0.001未満です（Claude Haikuモデル）。

アプリでの設定

  1. マイ情報（⚙タブ） → Anthropic APIキー（OCR）のセクションを開きます。
  2. フィールドにキーを貼り付け、保存をタップします。
  3. キーはお客様の端末の安全な領域（Android Keystore）に保存され、アプリのファイルに書き込まれることはありません。

使い方

  1. 請求書タブで↑アイコン（PDFインポート）をタップし、受領した請求書のPDFを選択します。
  2. フォームが開きます。✨ AIで分析ボタンをタップします。
  3. 少しお待ちください — 供給者、番号、日付、金額のフィールドが自動的に入力されます。
  4. 必要に応じて確認・修正し、保存をタップします。

APIキーがない場合、フォームは従来どおり機能します — すべてのフィールドを手動で入力してください。AIボタンは表示されません。

バックアップと復元

すべてのデータ（請求書、取引先、設定、PDF）は、マイ情報タブ → バックアップセクションからエクスポートおよび復元できます。

エクスポート

  • バックアップをエクスポートをタップします。
  • アプリがZIPファイル（billero_backup_YYYY-MM-DD.zip）を作成し、共有シートを開きます。
  • iCloud、Google Drive、メール、またはお好みの場所にファイルを保存します。

復元（例: 機種変更後）

  • 新しいスマートフォンにBilleroをインストールします。
  • マイ情報 → バックアップから復元を開きます。
  • 警告を確認します（既存のデータは置き換えられます）。
  • 保存場所からZIPファイルを選択します。
  • すべての請求書、取引先、設定、PDF、ロゴ、デジタル署名が復元されます。

警告: 復元すると既存のすべてのデータが置き換えられます。復元する前に、現在のデータのバックアップをエクスポートすることをお勧めします。

定期請求書

Billeroは、アプリを起動するたびに、定期的な請求書（週次、月次、または四半期）を自動的に生成します。

  1. 請求書タブで↻アイコン（右上） → 定期請求書をタップします。
  2. +をタップし、テンプレート名、取引先、サービスの説明、金額（VAT抜き）、VAT税率を入力します。
  3. 頻度を選択します: 週次、月次、または四半期。
  4. 月次／四半期の場合は、月の日付（1〜28）を選択します。
  5. 予定日以降の次回のアプリ起動時に、請求書がPDF付きで自動的に作成されます。

テンプレートはトグルで無効にしたり、いつでも編集したりできます。生成された請求書はメインの請求書リストに表示されます。

暗号通貨決済

Billeroは2種類の暗号通貨決済に対応しています: PDF請求書上の静的QRコードと、70種類以上の暗号通貨を受け取るためのCoingate決済リンクです。

PDF請求書上のQRコード — 対応する暗号通貨

マイ情報 → 暗号通貨決済でウォレットアドレスを設定します。QRコードはすべてのPDF請求書の2ページ目に自動的に追加されます。

  • EURC — Ethereum、Base、またはSolana上のCircle Euroステーブルコイン。レート: 1 EURC = 1 EUR。
  • USDC — Ethereum、Base、Polygon、またはSolana上のCircle USDステーブルコイン。レート: PDF生成時にFrankfurter API経由でECBから取得されます。
  • BTC — Bitcoin、BIP-21 QR形式。レート: PDF生成時にCoinGeckoから取得されます。
  • ETH — Ethereum（ネイティブ）、EIP-681 QR形式。レート: CoinGecko。
  • SOL — Solana（ネイティブ）、Solana Pay形式。レート: CoinGecko。
  • カスタムトークン — トークン名とウォレットアドレスを入力します。QRにはアドレスがエンコードされます（金額は合意による）。

レートと取得タイムスタンプが各QRコードの下に印刷されます。インターネット接続がない場合、QRコードは表示されません（レートは最新である必要があります）。

マイ情報 → 請求書に表示で、UPN QRと暗号通貨QRを個別に切り替えられます。UPNは1ページ目に残り、暗号通貨QRは2ページ目に表示されます。

Coingate決済リンク（BTC、ETH、SOL、および70種類以上のコイン）

  1. coingate.com でアカウントを作成し、APIキーを取得します。
  2. マイ情報 → CoingateでAPIキーを入力します。テスト用にはサンドボックスモードを有効にします。
  3. 請求書タブで、請求書の横にある₿アイコンをタップします。
  4. アプリが決済リンクを作成します — QRコードとブラウザで開くボタンが表示されます。
  5. リンクを顧客と共有します。顧客は好きな暗号通貨で支払います。
  6. EURがSEPA経由で銀行口座に振り込まれます（Coingateが変換を処理します）。
  7. アプリ内のステータスを確認ボタンで支払い状況を確認します。

CoingateはEUで規制されており（EMIライセンス、リトアニア）、SEPAでの振込に対応しています。

タイ — 2言語対応PDF（タイ語 + 英語）

プロフィールがタイ（TH）に設定されている場合、Billeroは自動的に2言語対応のPDF請求書を生成します: すべてのラベルがタイ文字（上）と英語（下）で同じページに並べて印刷されます。

  • タイ語フォント（Noto Sans Thai）はアプリに同梱されており、インストールは不要です。
  • 現地のタイの取引先にも、タイ語を読まない海外の取引先にも対応します。
  • VAT税率: 7%（歳入法典 第77条）。登録閾値: 年間THB 1,800,000。

シンガポール — GST請求書

プロフィールがシンガポール（SG）に設定されている場合、Billeroは自動的にGSTルールを適用します:

  • GST税率: 9%（GST法、第117A章）。
  • 登録閾値: 年間SGD 1,000,000 — 閾値未満の場合は免責事項が印刷されます。
  • 通貨: SGD（$）。支払い条件: 30日。
